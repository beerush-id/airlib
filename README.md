<h1 align="center">AIR Libraries</h1>

<p align="center">Production-ready libraries built on top of AIR Stack</p>

<p align="center">Fully typed libraries that leverage <a href="https://github.com/beerush-id/airstack">AIR Stack</a>'s fine-grained reactivity to deliver pre-built solutions for common application patterns — forms, API integrations, UI components, and utilities.</p>

## Libraries

### UI: Reactive Components
Pre-built UI components with fine-grained reactivity and full type safety.
- [@airlib/form](./ui/form) - Framework-agnostic reactive form engine (Zod-powered)
- [@airlib/react-form](./ui/react-form) - React form components
- [@airlib/solid-form](./ui/solid-form) - SolidJS form components

### IRPC: API Integrations
Type-safe remote function libraries built on IRPC transport.
- *Coming soon*

### Packages: Utilities
Shared utilities and helpers for AIR Stack applications.
- *Coming soon*
